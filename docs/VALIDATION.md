# 实验验证

检测评价采用 24 组可重复随机布局，覆盖四个方向、人员和障碍物两类目标及不同距离。类别一致且平面位置误差小于 1 m 记为场景检出。24/24 是场景级检出率，不是逐帧精确率。

本次保存 480 帧 RGB-D 数据，未匹配检测观测数为 0，静态分区分级正确率为 100%。单帧处理耗时 P95 为 33.41 ms；响应观测时差 P95 为 0.404 s，计时起点为场景位置更新前最近一次 ROS 时钟，包含场景服务和采样开销。

外参扰动为俯角 +1°、纵向平移 +2 cm。净空误差 P95 为 1.72 cm，边界跨越次数占有效采样点的 0.022%。数值来自本次有限场景样本，完整字段见 metrics.json。

动态验证覆盖前方 AEB 后倒车、后方 AEB 后前进、转弯 AEB、滑行减速与碰撞后驶离。静态近距等级与动态路径 AEB 分别评价。前后脱离测试的停车净空分别为 0.818 m 与 0.984 m；滑行指令速度斜率为 −0.25 m/s²。

复现顺序：启动仿真，运行 `excavator_safety.evaluation.scenario`，再运行 `excavator_safety.evaluation.metrics`；动态测试另行运行 `tests/integration/integration_path.py`。每组运行使用独立的数据目录与时间轴，避免跨运行合并统计。
